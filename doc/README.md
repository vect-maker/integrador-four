# Documentación del Proyecto Integrador IV

Este directorio centraliza las notas de arquitectura, convenciones técnicas y guías de configuración del proyecto:

- [Reglas de Oro para la Redacción de Objetivos](objectives_writing_rules.md): Lineamientos metodológicos formales (un solo verbo rector y agnosticismo tecnológico) para formular y auditar objetivos.
- [Hoja de Ruta Maestra y Plan de Hitos](paper_completion_roadmap.md): Plan integral, hitos, modelos matemáticos y seguimiento para la finalización del paper y diapositivas.
- [Matriz de Integración Curricular](curricular_integration.md): Mapeo formal entre los contenidos de los planes de componente curricular de Ciencia de Datos y las evidencias técnicas del proyecto.
- [Contexto Curricular del Semestre (Planes de Asignatura)](class_context/README.md): Programas analíticos oficiales del II año de Ciencia de Datos y su articulación con el Proyecto Integrador.
- [Especificación Integral MoviGo (API y Retos)](movigo_information.md): Especificación del negocio, endpoints de la API y retos académicos.
- [Declaración de Bibliografía Local para Linters de Typst](citations_linter_note.md): Explica la inclusión de `#show bibliography: none` y `#bibliography("../../references.bib")` en los capítulos modulares para compatibilidad con el linter de Typst (Tinymist).
